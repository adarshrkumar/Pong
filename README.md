# Pong

A classic Pong game built with Phaser.js game framework.

## Game Modes

- **Zero Player**: Watch AI vs AI
- **One Player**: Play against the computer
- **Two Player**: Local multiplayer

## Features

- Multiple game screens (loading, main game, end screen)
- Score tracking for both players
- Physics-based ball and paddle movement
- Responsive canvas sizing

## How to Play

1. Open the game in a browser
2. Select your game mode
3. Use keyboard controls to move your paddle
4. First to reach the target score wins

## Tech Stack

- [Phaser.js](https://phaser.io/) game framework
- HTML/CSS/JavaScript
- Arcade physics
- Hosted via GitHub Pages
